## 设计专属性判定

**约束内的专属性。** 视觉语言（纸白/夜底 + 唯一紫罗兰 + 发丝线 + One Dark 代码卡）是自建且彻底执行的——未发现组件级写死颜色；页面骨架（问候+列表+四个标准页）是类目通用的，而这是用户主动选择的 canon 方向，评审尊重该决策。错失的机会在内容层而非结构层：首屏没有任何"只有这个博客才有"的物件，"代码/图表/公式一等公民"的承诺只存在于文字里——问候语下的三行简介可以换成一行真实代码块或迷你 Mermaid 图，让差异化 3 秒内被看见。

**确定性扫描**：28 条发现全部为 advisory（22 字阶 / 4 圆角 / 2 颜色），核实后 20 真 / 8 误报；主要模式是 0.9375rem（8 处）与 1rem（6 处）两档事实上存在但未写入 DESIGN.md 的字号。**浏览器叠加**：detect.js 注入成功（首页 + 文章页，IAB 可变注入验证通过），两页均零 DOM 级标记——与 CLI 发现集中在 CSS 层相互印证。

## 整体印象

一个执行精度很高的 canon 博客：承诺过的东西（双主题无闪烁、代码/图表/公式、克制）全部兑现到实现细节。最大的机会不在修错——错误很少——而在"把专属性从 CSS 层提亮到内容层"，以及补齐无障碍的最后两块短板（抽屉焦点、触控目标）。

## 亮点

1. **Mermaid 管线的状态设计**：渲染前占位、失败回退等宽源码、themechange 重绘、防重复渲染——给第三方异步管线配全套状态 UI，支撑启发式 1 满分。
2. **主题系统完整闭环**：首帧前同步、color-scheme、双 media theme-color、圆形揭示 + reduced-motion 直切、切换事件驱动 Mermaid/giscus 换肤、localStorage try/catch。
3. **PostRow 整行链接 + 自我节制的层级**：整行热区、hover 只变底色、tabular-nums、两行截断——canon 方向执行的范本。

## 优先问题

1. **[P1] 移动目录抽屉是无焦点管理的 aria-modal 对话框** — role="dialog" aria-modal="true" 但打开不转移焦点、不圈闭 Tab、关闭不归还；键盘/读屏用户面对"宣告不存在却仍可穿越"的背景。修法：setOpen(true) 转移焦点入抽屉、sheet 内圈闭 Tab、关闭归还 FAB 焦点（或改原生 `<dialog>` + showModal()）。→ `$impeccable harden`
2. **[P2] 触控目标系统性 <44px** — 页头图标按钮 34×34、移动导航项高 34.5px、hero 链接 36.5px、tag pill 22px、页脚链接 34.5px；相邻导航项间距 2px。修法：≤640px 提升热区（padding-block 或 ::before 扩展），pill 在触控端加高。→ `$impeccable polish`
3. **[P2] 搜索页首访空态是一片虚空** — 无查询时输入框下 500px 空白，是全站唯一情绪低谷。修法：静态渲染示例词 chip（取自现有文章标题关键词）或最近 3 篇列表。→ `$impeccable onboard`
4. **[P2] PostRow `<a>` 嵌套 `<a>`（无效 HTML）** — 整行链接包裹标签胶囊链接，浏览器解析会在内层 a 截断外层 a，行链接实际不覆盖标签区。修法：TagPill 在行内改用 `<span role="link">` 结构或把 pill 移出 a、用 grid 叠放热区。→ `$impeccable harden`
5. **[P2] 不可见的 `#` 锚点是键盘陷阱** — JS 注入的标题锚点 opacity:0 但可 Tab 聚焦，focus outline 画在透明元素上。修法：`.prose .anchor:focus-visible { opacity: 1 }` 一行。→ `$impeccable polish`
6. **[P2] 字阶/令牌文档漂移** — 0.9375rem（8 处）与 1rem（6 处）为事实上存在未记录的隐含档位；4px/6px 微圆角未记录；--text-3 代码 #6a6a70 vs DESIGN.md #6f6f75；#b45309 未入文档。修法：DESIGN.md 补录或归并档位。→ `$impeccable document`

次要（P3）：⌘K 平台文案（Windows 显示 Ctrl K）、EC 复制按钮缺 aria-label、FAB 恒悬浮会压住正文右缘（可滚动向下时隐）、搜索页 56rem 与其余页 42rem 的左缘跳变、长文无返回顶部、两处内联 style、Mermaid 中文按字断行、404 的 4rem 超出声明最大字阶（文档补录即可）。

## 角色红旗

**Sam（无障碍依赖）**：抽屉 aria-modal 宣告与焦点行为自相矛盾（P1）；每个标题后的透明 `#` 锚点是看不见的 Tab 停留点。做得好：skip-link、全局 focus-visible、emoji aria-hidden、对比度全过 AA。
**Casey（移动分心）**：页头触控目标 34–41px 且相邻间距 2px，误触代价高；FAB 悬浮压住正文右缘。好的一面：静态零重资产、giscus 懒加载、整行热区。
**Jordan（新访客）**：搜索页空态无引导；"⌘K" 对非 Mac 用户是暗号。首页本身 5 秒可理解，无需修。
